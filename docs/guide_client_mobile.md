# Guide du client mobile 📱

*Pour les visiteurs des établissements : prendre un ticket et suivre son tour
depuis son téléphone.*

## 1. Installer l'application

1. Dans la salle d'attente ou sur la borne, repérez l'encart
   **« 📱 Suivez votre file depuis votre téléphone »**.
2. Scannez ce QR avec **l'appareil photo** de votre téléphone : la page
   d'installation s'ouvre.
3. Touchez **Télécharger l'application**, puis installez le fichier.
   Android peut demander d'autoriser « installer des applications
   inconnues » pour votre navigateur : acceptez (Paramètres → Applications).

## 2. Se connecter (aucun mot de passe)

1. Saisissez votre **adresse email** → **Recevoir un code**.
2. Un **code à 6 chiffres** arrive par email (valable 10 minutes).
   Rien reçu ? Vérifiez vos indésirables ; le bouton **Renvoyer le code**
   se réactive après 60 secondes.
3. Saisissez le code → vous êtes connecté pour ~3 mois sur cet appareil.

## 3. Prendre un ticket sur place

1. **Prendre un ticket** → l'écran de scan s'ouvre.
2. Scannez le **QR d'entrée du site** (affiché à l'accueil) — ou saisissez
   le **code du site** dans le champ du bas si la caméra est indisponible.
3. Choisissez votre file → **Prendre un ticket**. Votre numéro, votre
   position et l'attente estimée s'affichent.

## 4. Reprendre un ticket sans re-scanner — et à distance

Chaque site scanné apparaît ensuite sur l'accueil, section **« Mes sites »** :

- Touchez un site pour revoir ses files directement.
- Si la file l'autorise (bannière « Mode à distance »), vous pouvez prendre
  votre ticket **avant d'arriver** : l'attente estimée vous dit quand partir.
  Les files marquées « Ticket sur place uniquement » exigent d'être sur place.
- Appui long sur un site pour l'oublier.

## 5. Rendez-vous

1. Sur une file proposant le bouton **Rendez-vous** : choisissez un jour
   (14 prochains jours) puis un créneau libre.
2. Le jour J, une fois sur place, ouvrez votre rendez-vous et touchez
   **« Je suis arrivé(e) — m'enregistrer »** : vous recevez votre numéro et
   entrez dans la file (prioritaire si votre heure est passée).
3. ⚠️ Sans enregistrement dans l'heure qui suit l'heure prévue, le
   rendez-vous expire automatiquement (vous êtes prévenu par notification).

## 6. Suivre son tour

- L'écran du ticket se met à jour tout seul (position, attente estimée).
- Notifications : **« Bientôt votre tour »** quand vous approchez de la tête
  de file, puis **« C'est à vous ! »** avec le numéro du guichet — le
  téléphone **vibre et sonne** à ce moment. Toucher la notification ouvre
  votre ticket.
- **Annuler** est possible tant que vous n'êtes pas en cours de service.

## En cas de problème

| Symptôme | Explication / solution |
|---|---|
| « L'email n'a pas pu être envoyé » | Problème temporaire d'envoi côté établissement — réessayez dans un instant. |
| « Trop de tentatives » | Protection anti-abus — patientez le délai indiqué. |
| Écran noir au scan | Caméra refusée : autorisez-la dans les réglages, ou saisissez le code du site à la main. |
| Bandeau « Hors ligne » | Connexion perdue : l'app réessaie automatiquement, les infos affichées sont les dernières connues. |
| Déconnecté soudainement | Session expirée ou ouverte sur un autre appareil : reconnectez-vous par code email. |
| « Vous avez trop de tickets en cours » | Plafond de tickets simultanés atteint : annulez ou terminez un ticket existant. |
